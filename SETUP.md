# Setup Instructions

## Prerequisites
- Node.js (v14 or higher)
- npm

## Installation & Setup

### 1. Install Dependencies
```bash
npm install
```

This installs:
- **tailwindcss**: CSS framework for styling
- **postcss**: CSS processing tool
- **autoprefixer**: Automatically adds browser prefixes
- **compression**: Gzip compression for Express
- All other project dependencies

### 2. Build Tailwind CSS
Before running the development server, you MUST build the CSS:

```bash
# One-time build
npm run build:css

# Or watch mode for development (auto-rebuilds on HTML/JS changes)
npm run build:css:watch
```

This generates `static/css/output.css` which is linked in `index.html`.

### 3. Run Development Server
```bash
npm run dev
```

The server will start at `http://localhost:5000`

### 4. Production Build
```bash
npm run build:css      # Build CSS
npm start              # Start production server
```

## Important Notes

⚠️ **Do NOT use cdn.tailwindcss.com in production**
- We're using the Tailwind CLI for proper production builds
- The CDN is meant for prototyping only

⚠️ **Build CSS before deploying**
- Run `npm run build:css` before each deployment
- The compiled `output.css` is what gets served

## Troubleshooting

### No styles showing?
1. Run `npm run build:css`
2. Check that `static/css/output.css` exists
3. Hard refresh browser (Ctrl+Shift+R)

### Need to add new Tailwind classes?
1. Edit `index.html` or other template files
2. If in watch mode, CSS rebuilds automatically
3. If not in watch mode, run `npm run build:css`

### Want to customize colors?
Edit `tailwind.config.js` in the `theme.extend.colors` section:
```javascript
colors: {
    primary: '#5D5CDE',
    primaryDark: '#4A49B0',
    primaryLight: '#8180E7',
}
```

Then rebuild CSS: `npm run build:css`
